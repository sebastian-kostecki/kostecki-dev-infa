# Obsidian Self-hosted LiveSync (CouchDB) design

**Date:** 2026-08-19  
**Status:** Approved  
**Scope:** Run CouchDB for the Obsidian **Self-hosted LiveSync** plugin behind existing Traefik at `obsidian.kostecki.dev`

Upstream: [apache/couchdb](https://hub.docker.com/_/couchdb) · plugin [vrtmrz/obsidian-livesync](https://github.com/vrtmrz/obsidian-livesync)

This is **not** official Obsidian Sync.

---

## Decisions

| Topic | Choice |
|-------|--------|
| App domain | `obsidian.kostecki.dev` |
| Traefik compose | **Unchanged** — CouchDB is not added to repo-root `docker-compose.yml` |
| Source of truth | Templates in this repo under `stacks/obsidian-livesync/` |
| VPS layout | Copy templates to `/srv/apps/obsidian-livesync` via `scripts/deploy-obsidian-livesync.sh` |
| Separate GitHub app repo | **No** |
| DNS / CDN | Cloudflare **DNS only** (grey cloud) |
| Fauxton (`/_utils`) | Not public — Traefik rejects from the internet |
| Host ports | None — `proxy` network only |
| CORS / HTTP auth | CouchDB only — **no** Traefik CORS or extra BasicAuth |
| Image tag | Pin a concrete `couchdb:3.x.x` (not `latest`) |
| Secrets | `/srv/apps/obsidian-livesync/.env` only (not infra `.env`) |

## Architecture

```text
Internet
    │
    ▼
Cloudflare DNS only (no orange cloud)
    │
    ▼
Traefik (VPS, proxy network)          ← docker-compose.yml in this repo, unchanged
    │
    ├── kostecki.dev           → landing
    ├── budget.kostecki.dev    → wallet-master
    ├── vault.kostecki.dev     → vaultwarden
    └── obsidian.kostecki.dev  → couchdb :5984
                                 volume couchdb-data
                                 local.d/livesync.ini (CORS)
```

Public exposure: **Traefik only** (ports 80/443). CouchDB does not bind host ports.

Deploy copies stack files from git; the app directory is **not** a git clone. Manual edits to compose/INI on the VPS are overwritten on the next deploy. `.env` is never overwritten.

## DNS and Cloudflare

Add **A record → VPS IP**, **DNS only** (not Proxied):

| Record | Type | Value | Proxy |
|--------|------|-------|--------|
| `obsidian` | A | VPS IP | DNS only |

Let's Encrypt HTTP-01 (already configured on Traefik) issues the certificate. Do not enable Cloudflare proxy for this hostname — it often breaks CouchDB replication (body size, buffering).

Landing / budget / vault records — unchanged.

## Stack templates: `stacks/obsidian-livesync/`

| File | Purpose |
|------|---------|
| `docker-compose.yml` | CouchDB + Traefik labels + volume + INI mount |
| `local.d/livesync.ini` | CORS, `require_valid_user`, request/document size limits |
| `.env.example` | `COUCHDB_USER` / `COUCHDB_PASSWORD` placeholders |

### docker-compose.yml (outline)

- Image: pinned `couchdb:3.4.3`
- `container_name: couchdb`, `restart: unless-stopped`
- `env_file: .env`
- Volume `couchdb-data` → `/opt/couchdb/data`
- Bind `./local.d/livesync.ini` → `/opt/couchdb/etc/local.d/livesync.ini:ro`
- External network `proxy`
- Traefik: `Host(\`obsidian.kostecki.dev\`)`, entrypoint `websecure`, certresolver `letsencrypt`, port `5984`
- Higher-priority router for `PathPrefix(\`/_utils\`)` + IP allowlist `127.0.0.1/32` (403 from the internet)
- No Traefik CORS middleware

### Production `.env` (on VPS only)

```env
COUCHDB_USER=obsidian
COUCHDB_PASSWORD=<long-random-secret>
```

The official image creates the admin user on first start from these variables. Keep the same values on later restarts.

## Deployment procedure

### One-time (VPS)

```bash
# 1. Cloudflare DNS for obsidian → VPS IP (DNS only)

# 2. Pull infra
cd /srv/infra
git pull

# 3. Secrets (once)
mkdir -p /srv/apps/obsidian-livesync
cp stacks/obsidian-livesync/.env.example /srv/apps/obsidian-livesync/.env
# Edit COUCHDB_USER and COUCHDB_PASSWORD

# 4. Start
./scripts/deploy-obsidian-livesync.sh
```

If `.env` is missing, the deploy script copies `.env.example` and exits with an error until secrets are filled in.

### Updates

```bash
cd /srv/infra
git pull
./scripts/deploy-obsidian-livesync.sh
```

Data persists in the Docker volume `couchdb-data`.

### Obsidian client

1. Install **Self-hosted LiveSync**.
2. URI: `https://obsidian.kostecki.dev` (no port).
3. Database name e.g. `obsidian` (plugin may create it).
4. Username/password from the app `.env`.
5. Enable **end-to-end encryption** with a passphrase stored in a password manager.
6. Run the plugin CouchDB configuration check (CORS).

## Security and operations

- Firewall remains 22 / 80 / 443 only
- HTTPS via Traefik + Let's Encrypt
- `require_valid_user` in CouchDB
- Fauxton not reachable from the internet
- Grey cloud exposes the VPS IP on this hostname — mitigated by CouchDB auth + client E2E
- `.env` only on VPS (never commit)
- No off-site backup of `couchdb-data` in this scope (follow-up)

---

## Error handling

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| 502 | Container not on `proxy` | `docker network inspect proxy` |
| SSL failure | DNS not ready or hostname still Proxied | Grey cloud; wait for ACME; Traefik logs |
| CORS errors in the plugin | Reverse proxy adding CORS, or INI not mounted | Do not add Traefik CORS; redeploy INI |
| Replication timeouts / large files | Cloudflare Proxied, or Traefik body limits | DNS only; later Traefik `buffering` if needed |
| 403 on `/_utils` | Expected | Do not use Fauxton over the internet |
| Deploy exits asking for `.env` | First run | Fill `COUCHDB_*` and rerun |
